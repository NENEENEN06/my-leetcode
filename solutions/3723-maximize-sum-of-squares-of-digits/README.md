# 3723. Maximize Sum of Squares of Digits

- Difficulty: Medium
- Topics: Math, Greedy
- Language: C++
- 题目链接: https://leetcode.cn/problems/maximize-sum-of-squares-of-digits/

## 题目

给定 `num`（位数）和 `sum`（各位数字之和），构造一个恰有 `num` 位、各位和为 `sum` 的整数，使「各位数字平方和」最大；答案要求数字本身也最大，无解返回空串。

## 我的思路

- 平方是凸函数：在数字之和固定的前提下，把数字推得越极端（越靠近 0 或 9），平方和越大。所以最优解一定长成「一堆 9 + 一个余数 + 一堆 0」。
- 位数固定为 `num`，能放下的最大和是 `9 * num`，`sum > 9 * num` 直接返回 `""`（代码里靠循环结束后 `sum` 是否被清零来判断）。
- 贪心从左往右填：只要还剩 `sum > 9` 就放一个 9，`sum -= 9`；第一处不再是「满 9」的位置放上剩下的余数，后面补 0。
- 把余数放在最后那个 9 的**下一位**、而不是塞到末尾，顺带满足了「有多个答案时返回最大的那个数」——高位越大数值越大，`9920` 优于 `9902`。

## 代码

```cpp
// 3723. Maximize Sum of Squares of Digits
// 从最高位开始尽量填 9，剩下的和一次填进当前位；填不满 num 位说明无解。
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        string res(num, '0');   // 先占满 num 位，之后逐位靠字符偏移填数字
        for (int i = 0; i < num; i++) {
            if (sum > 9) {
                res[i] += 9;
                sum -= 9;
            } else {
                res[i] += sum;
                sum = 0;
                break;
            }
        }
        if (sum) {
            return "";   // 还有没分配完的和，说明 9*num 都不够，凑不出这个数
        }
        return res;
    }
};
```

## 另一种写法

同一思路压成一行（利用 `sum/9` 直接得到 9 的个数）：

```cpp
class Solution {
public:
    string maxSumOfSquares(int num, int sum) {
        return (sum>num*9)?"":(string(sum/9,'9')+((sum==num*9)?"":(string(1,char('0'+sum%9))+string(num-sum/9-1,'0'))));
    }
};
```

两版等价：`sum == 9 * num` 时全 9；否则 `sum/9` 个 9 + 一个 `sum%9`（`sum%9 == 0` 时这一位就是 `0`，等价于「余数为 0」）+ 补 0 到 `num` 位。一行的可读性差一些，但省掉了循环里对 `sum` 的反复修改。

## 代码分析

- 正确性：正确
- 关键实现：`res` 预先填成 `num` 个 `'0'`，循环里用 `res[i] += k` 直接在字符上做偏移；`sum > 9` 是严格的（等于 9 时该位就是 9 并收尾，不再多走一轮）
- 潜在 Bug：无。几点细节：① `res` 预留了 `num` 个位置，循环最多走 `num` 次，余数一定能在第 `num` 位之前落下，不会越界；② `sum > 9*num` 时循环会填满全部 `num` 位而 `sum` 仍大于 0，靠末尾 `if (sum)` 返回 `""`，判断位置在循环之后是对的；③ 把余数填在下一位、后面全 0，正好同时满足「数值最大」的要求，不需要额外排序或比较
- 可以改进的地方：`sum > 9` 的判断可以换成直接算 `sum / 9`（即上面的第二种写法）；当前写法更直白，不改也行

## 复杂度

- 时间复杂度：O(num)，最坏把每一位都写一遍
- 空间复杂度：O(1) 额外空间（返回的字符串本身占 O(num)，不计入）

## 易错点

- 无解条件是 `sum > 9 * num`（而不是 `sum >= 9 * num`），恰好等于时是最多 9 的解，不是无解。
- `sum > 9` 要用严格大于：写成 `>=` 会在 `sum == 9` 时多消耗一位，剩下本该是 9 的位置变成 0。
- 余数要放在高位侧（9 串的下一位），放到末尾会得到数值更小的解，违反「返回最大的那个」。
- 边界：`sum == 0` 时输出 `num` 个 `0`（如 `num=2, sum=0` → `"00"`）；题目给的用例里 `sum` 都是正数，遇到 `sum = 0` 的隐藏样例要确认期望是 `"00"` 还是空串。
- 数字位数到 `num` 位、数值不需要转成整数，全程按字符串拼装，不会溢出。

## 总结

「数字之和固定、求平方和最大」的通用结论：**平方和最大化 = 让数字尽可能极端**，也就是先把 9 用满、余数单独占一位、剩下补 0。这类题的实现套路是「先判无解上界 `9*num`，再贪心填高位」，同时注意题目对「数值最大」的附加要求（把余数放高位而不是末位）。

## 复盘

- 关键突破点：认清平方是凸函数，最优点一定在边界（0 和 9）上，于是完全不用搜索，直接贪心。
- 一行流写法把「9 的个数 = `sum/9`、余数单独一位、其余补 0」表达得很紧凑；想清楚这三段再写，比循环里反复改 `sum` 更容易一次写对。
- 下次看到「固定位数 + 固定数字和 + 最值」，先算可行上界，再想极值分布。
