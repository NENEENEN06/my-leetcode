# 0835. Image Overlap

- Difficulty: Medium
- Topics: Array, Matrix
- Language: C++
- 题目链接: https://leetcode.cn/problems/image-overlap/

## 题目

给定两个大小均为 `n x n` 的二进制矩阵 `img1` 和 `img2`（元素只有 0 和 1）。可以把其中一个矩阵整体向左 / 右 / 上 / 下滑动任意单位（不能旋转），再叠放到另一个矩阵上；移出边界的 `1` 直接消失。要求返回两个矩阵在同一位置**都为 1** 的最大格子数。

## 我的思路

- 核心思想：**枚举所有平移偏移量 + 逐个偏移量暴力统计重叠**。因为答案只依赖于相对位移，而 `n <= 30`，可行偏移量只有 `(2n-1)^2` 个，每个偏移量的比较区域最多 `n^2` 个格子，直接枚举即可，不需要找规律或优化。
- 使用的数据结构：直接复用输入的 `img1`、`img2`，只用 `cnt`、`ans` 两个整数，没有额外数组。
- 算法流程：
  1. 双重循环枚举偏移量 `i, j ∈ [1-n, n-1]`。这里 `(i, j)` 表示\"`img1` 相对 `img2` 的坐标偏移\"：`img1` 的 `(x+i, y+j)` 与 `img2` 的 `(x, y)` 对齐。`1-n .. n-1` 正好覆盖了从\"几乎完全错开\"到另一边\"几乎完全错开\"的全部有效相对位置。
  2. 对固定偏移 `(i, j)`，用 `x`、`y` 遍历 `img2` 的所有格子，通过 `x+i<0` / `y+j<0` 的 `continue` 跳过落到 `img1` 边界外的坐标，循环上界 `x+i<n` 保证 `img1` 下标不越界；剩下的合法坐标就是两个矩阵真正重叠的区域。
  3. 在重叠区域里统计 `img1[x+i][y+j] == 1 && img2[x][y] == 1` 的格子数 `cnt`，用 `ans` 取最大值。
  4. 所有偏移量枚举完后返回 `ans`。
- 关键状态 / 变量：`(i, j)` 是相对平移量；`cnt` 是当前平移下的重叠 1 数；`ans` 是历史最优。`x+i<n&&x<n`、`y+j<n&&y<n` 是下标合法性边界。
- 为什么这样做：题目要求的是\"把其中一个矩阵平移任意单位后的最大重叠\"，而平移的可能情况是有限的——任意一次平移都等价于某个整数偏移 `(i, j)`，且题目允许清除出界的 `1`，所以只需对每个候选偏移老老实实数一遍重叠 1，取最大即可。
- 为什么能够得到正确答案：`(i, j)` 遍历了全部 `(2n-1)^2` 种可能相对位置（平移方向对称，`img1` 平移 `(-i,-j)` 与 `img2` 平移 `(i,j)` 等价，所以只枚举一个方向也能覆盖），而每个偏移下 `x, y` 又遍历了全部可能相交的格子，因此既不漏解也不重解，取最大就是全局最优。

## 代码

```cpp
class Solution {
public:
    int largestOverlap(vector<vector<int>>& img1, vector<vector<int>>& img2) {
        int n=img1.size();
        int ans=0;
        for(int i=1-n;i<n;i++){
            for(int j=1-n;j<n;j++){
                int cnt=0;
                for(int x=0;x+i<n&&x<n;x++){
                    if(x+i<0){continue;}
                    for(int y=0;y+j<n&&y<n;y++){
                        if(y+j<0){continue;}
                        if(img1[x+i][y+j]==1&&img2[x][y]==1){
                            cnt++;
                        }
                    }
                }
                ans=max(cnt,ans);
            }
        }
        return ans;
    }
};
```

## 代码分析

- 正确性：正确。`(i, j)` 覆盖了全部相对位移，内层用边界判断把所有 `img1` 越界的位置裁掉，等价于题目中\"越过边界的 1 被清除\"；重叠区域的计数逻辑与题面定义一致。
- 关键实现：
  - 上界写成 `x+i<n && x<n`：`i >= 0` 时 `x+i<n` 即 `x < n-i`，已经蕴含 `x < n`；`i < 0` 时 `x+i<n` 恒成立（`x < n-i > n`），此时由 `x<n` 收口。两个条件合起来才在 `i` 正负两侧都给出正确上界。
  - 用 `continue` 而不是调 `i = max(0, -i)` 起步，是为了让 `x, y` 始终按 `img2` 的自然下标从 0 开始，少一层变量换算，逻辑上更直观。
  - `ans` 初值 0 天然覆盖了\"全 0 矩阵\"和\"完全无法重叠\"的情况。
- 潜在 Bug：没有会导致答案错误的 bug。只有两处冗余，属于写法层面的小瑕疵：
  - `x < n`、`y < n` 在 `i, j >= 0` 时是多余条件（`x+i<n` 已保证更紧的上界）；
  - `if(x+i<0){continue;}` 的位置在内层循环之外时可以用循环起点代替，放在这里相当于每次多比较一次、并让内层 `y` 循环整体空转一圈（`x+i<0` 时内层每个 `y` 都会走 `y+j<0` 判断或少走一次比较），不影响正确性，只影响常数。
- 可以改进的地方（思路层面的选择，不是错误）：
  - 只枚举 `1` 的位置：把 `img1`、`img2` 中所有 `1` 的坐标取出来（`p1`、`p2`），枚举点对 `(p1, p2)`，把偏移量 `(p1.x - p2.x, p1.y - p2.y)` 在计数数组里 `+1`，最后取计数数组最大值。复杂度降到与 `1` 的个数相关（最坏仍是 O(n^4) 级别的点对数，但全 0 或稀疏时极快），代码也更短。
  - 位运算 / `bitset` 优化：把每一行压成 bit，对每个偏移量做\"移位 + 按位与 + 数 1\"，可做到 O(n^3 / 64) 量级。
  - 理论最优方向是二维 FFT（O(n^2 log n)），但对 `n <= 30` 完全没必要。

## 复杂度

- 时间复杂度：O(n^4)。外层 `(2n-1)^2 ≈ 4n^2` 个偏移量，每个偏移量内层最多扫 `n^2` 个格子；本题 `n <= 30`，最坏约 `59 × 59 × 900 ≈ 3.1 × 10^6` 次比较，可轻松通过。
- 空间复杂度：O(1)。只使用了常数个整型变量，没有额外数组（输入矩阵不计入）。

## 易错点

- **偏移量范围写错**：必须是 `[1-n, n-1]`（或 `-(n-1) .. n-1`）共 `2n-1` 个取值。少枚举一侧就会漏掉\"只有一个角相交\"这类解。
- **越界访问**：`img1[x+i][y+j]` 的下标要先保证 `0 <= x+i < n` 且 `0 <= y+j < n`，负数是 C++ 里最容易翻车的地方（`vector` 的 `operator[]` 不做检查，负下标是未定义行为）。
- **平移方向误解**：枚举 `(i, j)` 与 `(-i, -j)` 是对称的，只要范围完整，把 `img1` 当成被平移方还是 `img2` 当成被平移方都不影响答案。
- **误以为需要模拟\"移动\"**：不需要真的构造出移动后的矩阵，用坐标偏移做下标映射即可。
- `n = 1` 的退化情况：只有偏移 `(0,0)`，逻辑自然成立，不需要特判。

## 总结

- 本题的关键是**把\"平移图像\"翻译成\"枚举整数坐标偏移\"**：一旦这么建模，问题就退化成一个可以直接暴力扫描的计数问题。
- 数据范围 `n <= 30` 是明确的信号：`O(n^4)` 的暴力（约 `3 × 10^6`）完全够用，不必为了最优复杂度写 FFT 或位运算。
- 枚举偏移 + 合法区域裁剪是图像 / 网格类问题的通用套路，写的时候把\"下界裁剪\"和\"上界裁剪\"分开想清楚，就不容易漏掉负数一侧。

## 复盘

- 我哪里容易想错：容易只枚举 `0 .. n-1` 的偏移量，漏掉反向平移；也容易在负数下标边界上写错判定条件。
- 关键突破点：想清楚 `(i, j)` 的物理含义（`img1[x+i][y+j]` 对齐 `img2[x][y]`），再用 `x+i<n` 与 `x+i<0` 两条约束把重叠区域圈出来。
- 下次看到什么特征应该想到这个算法：网格上\"平移 / 覆盖 / 最大重合\"、`n` 很小（<= 30~50）、需要枚举相对位置时，先写\"枚举偏移 + 暴力统计\"，再看是否需要位运算或卷积优化。
