# 1021. Remove Outermost Parentheses
- Difficulty: Easy
- Topics: String, Stack
- Language: C++
- 题目链接: https://leetcode.cn/problems/remove-outermost-parentheses/

## 题目
合法括号串可以唯一拆成若干个「原语」（最外层并列的括号组，如 `(()())(())` 拆成 `(()())` 和 `(())`）。把每个原语**最外层的那一对括号去掉**，其余字符按原顺序拼接，返回结果。

## 我的思路
不用真的去找原语边界，用深度计数器 `left` 一趟扫描即可：

- 遇 `(`：`left++`；如果自增后 `left != 1`，说明这一对不是某个原语的**最外层左括号**，保留它。
- 遇 `)`：先 `left--`；如果自减后 `left != 0`，说明这一对不是某个原语的**最外层右括号**，保留它。
- 被跳过的恰好是「把深度从 0 抬到 1 的 `(`」和「把深度从 1 降回 0 的 `)`」，也就是每个原语的首尾字符。

为什么正确：括号串的深度（未闭合左括号数）回到 0 的位置就是原语的分界。某个 `(` 使深度由 0→1，它必然是某个原语的开头；某个 `)` 使深度由 1→0，它必然是某个原语的结尾。二者正是要去掉的两类字符，其余字符全部保留即可。

## 代码
```cpp
class Solution {
public:
    string removeOuterParentheses(string s) {
        string res;
        int left=0;
        for(auto ch:s){
            if(ch=='('){
                left++;
                if(left!=1){
                    res+=ch;
                }
            }
            else{
                left--;
                if(left!=0){
                    res+=ch;
                }
            }
        }
        return res;
    }
};
```

## 代码分析
- 正确性：正确。随机对拍用**另一种算法**（先按深度回零切出每个原语，再对每段 `substr(1, len-2)` 拼接）做参照，随机合法括号串 20 万组零不一致；经典用例 `"(()())(())"` → `"()()()"`、`"(()())(())(()(()))"` → `"()()()()(())"`、`"()()"` → `""` 全部吻合。
- 关键实现：两个 `if (left != 1)` / `if (left != 0)` 的判断时机是关键——**必须在自增/自减之后**判断，此时 `left` 表示的正是「当前字符所处的新深度」。
- 潜在 Bug：无（输入保证是合法括号串）。
- 可以改进的地方：
  1. `res` 可以 `reserve(s.size())`，避免中途多次扩容（本题规模无感，但习惯好）。
  2. `left` 命名成 `depth` 更达意；`for(auto ch : s)` 写 `for(char ch : s)` 更准确表达「只读」。
  3. 也可以写成 `if(ch=='(' && ++left > 1) res+=ch;` / `else if(--left > 0) res+=ch;` —— 更紧凑，但可读性下降，初学不建议。

## 复杂度
- 时间复杂度：O(n)。一次线性扫描，每个字符常数次操作（`res += ch` 摊销 O(1)）。
- 空间复杂度：O(n)。答案串长度接近 n（不含入参）；除答案外额外空间 O(1)，不需要栈。

## 易错点
- **判断时机放在自增/自减之前**：若写成「先判断后自增」，`left` 的含义变成「读这个字符之前的深度」，`(()())` 这类串会多保留/少保留括号，结果出错。
- **条件写成 `left > 1` / `left < 0`**：`(` 分支要求「新深度 ≥ 2 才保留」，`>` 与 `!=` 在本题目（合法串）下等价，但语义上 `!= 1` 更直接对应「不是最外层」；`(` 分支不要写成 `left == 0`。
- **误以为只需去掉第一个和最后一个字符**：只有当整串是一个原语时才成立（`()()` 去掉首尾会得到 `)(`），必须按原语逐个处理。
- **想用栈来实现**：栈当然可以（记录原语边界），但本题用深度计数就够，多用一个容器没必要。
- **非法输入**：题目保证合法；若输入可能不合法（例如 `"(()"`），深度不会回到 0，算法会保留部分括号并返回不合预期的串，需要额外处理。
- **空串**：`s = ""` 时循环不执行、返回空串，符合题意。

## 总结
「去掉每个原语的最外层括号」等价于「去掉所有让深度从 0 变 1 的 `(` 与让深度从 1 变 0 的 `)`」——这是**深度计数法**的又一次应用：只要能用一个计数器刻画前缀状态，就不需要真的做括号匹配或切分。括号家族（有效性判断、最长有效、嵌套深度、得分、拆分、最少插入）几乎都可以用同一个深度计数器推出不同结论。

## 复盘
- 容易想错的地方：先去按原语切分字符串（可行但代码更长，还要处理多个原语），或者以为「去掉首尾字符」就够了。
- 关键突破点：注意到原语的边界就是深度归零的位置，于是「该删哪些括号」可以完全由「自增/自减之后的深度」判断，一趟扫描解决。
- 下次看到什么特征应该想到这个算法：题目按结构（原语/最外层/嵌套层）做筛选时，先想「哪些字符让深度跨越了某个阈值」，往往一个计数器就能筛出目标集合。
