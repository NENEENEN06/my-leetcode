# 3483. Unique 3-Digit Even Numbers

- Difficulty: Easy
- Topics: Enumeration, Array, Hash Table
- Language: C++
- 题目链接: https://leetcode.cn/problems/unique-3-digit-even-numbers/

## 题目

给定一个数字数组 `digits`，从其中选出三个数字拼成一个**三位偶数**，要求每个数字**最多使用一次**（按它在数组中出现的次数计），且**不能有前导零**。求能组成的不同三位偶数的数量。

## 我的思路

- 核心思想：先用计数数组统计每个数字的出现次数，再按「百位 → 十位 → 个位」枚举所有合法组合。因为枚举的对象是**数字本身**而不是数组下标，重复的三位数天然只会被统计一次，于是"不同"这一要求被自动满足。
- 使用的数据结构：`int cnt[10]`，当作"每个数字还剩几次可用"的多重集合；`ans` 累加计数。
- 算法流程：
  1. 遍历 `digits`，`cnt[d]++` 记录每个数字的可用次数。
  2. 枚举百位 `i`：从 `1` 到 `9`（排除前导零），要求 `cnt[i] > 0`。
  3. 选定 `i` 后 `cnt[i]--`；再枚举十位 `j`：从 `0` 到 `9`，要求 `cnt[j] > 0`。
  4. 选定 `j` 后 `cnt[j]--`；再枚举个位 `k`：`0,2,4,6,8`（保证是偶数），只要 `cnt[k] > 0` 就说明这一组 `(i,j,k)` 构成一个合法三位偶数，`ans++`。
  5. 每层枚举结束把 `cnt` 还原（`cnt[j]++`、`cnt[i]++`），回到上一层继续。
- 为什么这样做：三个数位的取值一旦确定，这个三位数就唯一确定；因此只要把所有合法的 `(百, 十, 个)` 取值组合枚举一遍即可。用 `cnt` 的递减表示"这次使用占掉该数字的一份"，就能正确表达数组中同一数字出现多次的情形（例如 `[0,2,2]` 里数字 `2` 可以用两次）。
- 关键状态 / 变量：`cnt[10]` 表示各数字的剩余可用次数（枚举过程中临时递减、回溯时还原）；`i`、`j`、`k` 分别是百位、十位、个位的取值，其中 `k` 只取偶数。
- 为什么能够得到正确答案：每个不同的三位偶数都恰好对应一组唯一的 `(i,j,k)`，枚举时每个合法组合正好命中一次；`i` 从 `1` 起排除了前导零，`k` 只取偶数保证了末位为偶，`cnt` 约束保证了不会超量使用某个数字。因此计数既不重复也不遗漏。

## 代码

```cpp
class Solution {
public:
    int totalNumbers(vector<int>& digits) {
        int cnt[10]={0};
        int ans=0;
        for(auto i:digits){
            cnt[i]++;
        }
        for(int i=1;i<=9;++i){
            if(!cnt[i]){continue;}
            cnt[i]--;
            for(int j=0;j<=9;++j){
                if(!cnt[j]){continue;}
                cnt[j]--;
                for(int k=0;k<=9;k+=2){
                    if(cnt[k]){ans++;}
                }
                cnt[j]++;
            }
            cnt[i]++;
        }
        return ans;
    }
};
```

## 代码分析

- 正确性：正确。
- 关键实现：以数字值（而非下标）为枚举维度，配合频次数组的"递减 / 还原"，一趟枚举同时完成了"去重"和"使用次数受限"两件事。
- 潜在 Bug：单独看没有逻辑错误。需要注意 `cnt` 的递减与还原必须成对出现，否则会污染后续枚举（本代码中 `cnt[i]--/++`、`cnt[j]--/++` 各自对称，正确）。
- 可以改进的地方：当前写法在正确性、复杂度、可读性上都已足够好，无需修改。若换成"枚举下标再放进 `std::set` 去重"会退化为 O(n³·log) 且代码更长，反而不如本解。

## 复杂度

- 时间复杂度：O(n)。统计词频为 O(n)（n = digits.length ≤ 10）；三层枚举是固定规模的常数级（百位 9 种 × 十位 10 种 × 个位 5 种 = 450 次）与 n 无关，可视为 O(1)。整体 O(n)。
- 空间复杂度：O(1)。只用到一个长度为 10 的计数数组，与输入规模无关。

## 易错点

- 百位必须从 `1` 起枚举：`i = 0` 会产生前导零（如 `012`），必须排除。
- 个位只枚举偶数：`k` 从 `0` 开始、步长为 `2`（`0,2,4,6,8`）；若写成 `k++` 会把奇数末尾也算进去。
- 同一数字在数组中出现多次时可被使用多次（如 `[0,2,2]` 可组成 `202`、`220`），要用频次数组递减来处理，不能简单地用 `bool` 判重。
- 枚举粒度是"数字值"，所以天然保证"不同"；若按数组下标枚举，必须额外去重，否则同一个数会被重复计数。
- `cnt` 在选定某位后递减，一定要在同层结束前还原，否则会影响到同层与上层的后续枚举。

## 总结

「**按位枚举取值 + 频次数组约束**」是"从给定数字集合中拼出某个数、要求互不相同且每个数字使用次数有限"这类问题的通用套路：以最终结果的各位数字为枚举维度，用频次数组表达"还剩几次可用"，就同时满足了"不同"和"每个数字用一次"两个限制。本题数字种类固定为 10，枚举空间是常数级，因此整体等价于一遍线性扫描。

## 复盘

- 关键突破点：把"不同三位偶数的数目"转化为对「百位 × 十位 × 个位」取值组合的枚举——取值确定则数唯一，去重是自动的；再借助频次数组把"数字可用次数"编码进状态。
- 下次看到什么特征应该想到这个算法：从给定的数字/字符池里拼数或拼串，要求结果"互不相同"且"每个元素使用次数受限"，优先考虑「按位枚举 + 可用次数（频次）数组」这一模板。
