# 2124. Check if All A's Appears Before All B's

- Difficulty: Easy
- Topics: String
- Language: C++
- 题目链接: https://leetcode.cn/problems/check-if-all-as-appears-before-all-bs/

## 题目

给定一个仅由 `a` 和 `b` 组成的非空字符串，判断是否所有 `a` 都在所有 `b` 前面。只有一种字符时也满足要求。

## 我的思路

不必统计两个字母各有多少个，只要查找相邻的 `ba`：找到了就返回 `false`，找不到就返回 `true`。

## 代码

```cpp
class Solution {
public:
    bool checkString(string s) {
        return s.find("ba") == string::npos;
    }
};
```

## 代码分析

- **找到 `ba` 就一定违规**：这个子串里的 `b` 出现在 `a` 前面，已经构成反例。
- **违规就一定能找到 `ba`**：如果某个 `b` 右侧还有 `a`，从这个 `b` 往右找第一个 `a`。从该 `b` 到这个 `a` 之前没有 `a`，而题目只允许两种字符，所以这个 `a` 的前一个字符必是 `b`。因此只检查相邻的 `ba` 就足够。
- `s.find("ba")` 在未找到时返回 `string::npos`。代码取自力扣 Accepted 提交 `761093491`，只调整了缩进与空格——`s` 是题面签名里的参数名，保持原样。

## 复杂度

- 时间：`O(n)`，其中 `n` 为字符串长度；模式固定为两个字符，查找至多扫描线性数量的字符。
- 额外空间：查找本身为 `O(1)`；当前签名按值接收字符串，若从左值调用，复制参数另需 `O(n)` 时间和空间。

## 易错点

- `ab` 是合法的分界，违反顺序的是 `ba`，不要把模式写反。
- `a`、`b`、`aaaa`、`bbbb` 都应返回 `true`；`bbba` 应返回 `false`，即使违规的 `ba` 出现在末尾。
- 结论依赖字符集只有 `a` 和 `b`；若允许第三种字符，`bca` 就是没有相邻 `ba` 却仍然乱序的例子。

## 总结

合法串只能由一段 `a` 接一段 `b` 组成，两段都允许为空；查找相邻的 `ba` 即可判定。
