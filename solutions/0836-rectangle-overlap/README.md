# 836. Rectangle Overlap
- Difficulty: Easy
- Topics: Math, Geometry
- Language: C++
- 题目链接: https://leetcode.cn/problems/rectangle-overlap/description/

## 题目
给定两个轴对齐的矩形 rec1、rec2，每个矩形用 [x1, y1, x2, y2] 表示，(x1, y1) 为左下角、(x2, y2) 为右上角。判断两者是否存在面积大于 0 的重叠区域（仅边或点相接不算重叠）。

## 我的思路
用「两个坐标轴上都不分离」来判定，而不是去算交集面积。
- 两个轴对齐矩形重叠 ⟺ x 方向的区间相交 且 y 方向的区间相交。
- 第一个方向：`rec2[0] < rec1[2]` 说明 rec2 的左边界没跑到 rec1 右边界的右侧，`rec2[1] < rec1[3]` 说明 rec2 的下边界没跑到 rec1 上边界的上方 —— 即 rec2 没有完全呆在 rec1 的右侧或上方。
- 再反向写一遍：`rec1[0] < rec2[2]`、`rec1[1] < rec2[3]`，排除 rec1 完全呆在 rec2 右侧或上方的情况。
- 两组条件同时成立，说明两者在任何一轴上都分离不了，必然有正面积交集，直接返回 true；否则 false。
- 关键状态：无，只有四个边界值比较；四个条件全部用严格小于 `<`。
- 为什么正确：这套条件正是 x 区间相交与 y 区间相交的展开形式，且严格小于把「边贴边、点相接」这类零面积接触排除在外。

## 代码
```cpp
class Solution {
public:
    bool isRectangleOverlap(vector<int>& rec1, vector<int>& rec2) {
       if(rec2[0]<rec1[2]&&rec2[1]<rec1[3]&&rec1[0]<rec2[2]&&rec1[1]<rec2[3]) return true;
       return false;
    }
};
```

## 代码分析
- 正确性：正确。四个严格不等式恰好等价于「x 区间相交 ∧ y 区间相交」。
- 关键实现：前两条判断 rec2 没有完全位于 rec1 的右侧/上方，后两条判断 rec1 没有完全位于 rec2 的右侧/上方；四条同时成立即相交。
- 潜在 Bug：无。题目保证每个矩形满足 x1 < x2、y1 < y2，不存在退化输入。
- 可以改进的地方：仅可读性——可把两条 x 判断、两条 y 判断相邻书写（`rec2[0] < rec1[2] && rec1[0] < rec2[2] && rec2[1] < rec1[3] && rec1[1] < rec2[3]`），或写成 `max(左) < min(右) && max(下) < min(上)`，甚至直接 `return` 该表达式省掉 if。不影响正确性。

## 复杂度
- 时间复杂度：O(1)。只做常数次数组访问和比较，与坐标数值无关。
- 空间复杂度：O(1)。没有使用额外容器。

## 易错点
- 把 `<` 写成 `<=`：边或点相接的用例（如 rec1=[0,0,2,2]、rec2=[2,2,3,3]）会被误判为重叠。
- 只写一组条件：只判断 rec2 相对 rec1 的关系，会漏掉 rec1 位于 rec2 右上方向的情形。
- 记错数组语义：[x1, y1, x2, y2] 是左下角 + 右上角，不是左上角 + 右下角。
- 用面积法求交集：坐标差可能为负，直接比边界更安全。

## 总结
轴对齐矩形重叠的判定，本质是两个一维区间相交的直积：`max(左) < min(右) && max(下) < min(上)`。记住严格小于 —— 只有正面积交集才算重叠。
