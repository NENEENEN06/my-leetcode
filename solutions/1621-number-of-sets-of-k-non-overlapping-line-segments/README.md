# 1621. Number of Sets of K Non-Overlapping Line Segments
- Difficulty: Medium
- Topics: Math, Dynamic Programming, Combinatorics
- Language: C++
- 题目链接: https://leetcode.cn/problems/number-of-sets-of-k-non-overlapping-line-segments/

## 题目
在一条线上有 n 个点（编号 0 到 n-1），从中选出 k 条互不重叠的线段（线段可以共端点）。求不同的选法数量，答案对 1e9+7 取模。

## 我的思路
把「选 k 条线段」变成「从左到右扫点，逐步决定每条线段的右端点在哪」，用两个互补的状态做 DP，避免枚举每条线段的左右端点。

- `dp[i][j]`：只考虑前 i 个点，已经选定 j 条线段，且**第 j 条线段正好以点 i 为右端点**的方案数。
- `f[i][j]`：只考虑前 i 个点，已经选定 j 条线段，且**点 i 没有被最后一条线段当作右端点**的方案数（即最后一条线段在 i 之前就结束了）。
- 两个状态互补，任一时刻最后一条线段的右端点要么是 i，要么不是。

转移（都取模）：

- `dp[i][j] = f[i][j-1] + dp[i-1][j]`
  - 前一条：前 j-1 条线段都已结束在 i 之前（`f[i][j-1]`），此时点 i-1 和 i 之间还没被占用，第 j 条线段直接在 i-1 → i 上开一条新线段；
  - 后一条：第 j 条线段本来以 i-1 为右端点（`dp[i-1][j]`），把它的右端点往右挪一格延伸到 i，线段条数不变。
- `f[i][j] = dp[i-1][j] + f[i-1][j]`：点 i 不作为右端点时，前 i-1 个点的状态照搬 —— 点 i-1 是右端点（`dp[i-1][j]`）或不是（`f[i-1][j]`）都合法。
- 边界：`f[i][0] = 1`（一条线段都不选，只有一种方案）；`j` 只需枚举到 `min(i-1, k)`，因为 i 个点最多画出 i-1 条线段。
- 最后一条线段的右端点可能是点 n，也可能不是，所以答案是 `dp[n][k] + f[n][k]`。

之所以能对，是因为每条线段只由「右端点在哪」唯一刻画：新开一条线段走 `f[i][j-1]` 分支，延长现有线段走 `dp[i-1][j]` 分支，两条分支覆盖了「第 j 条线段以 i 结尾」的全部来源，没有重复计数。

## 代码
```cpp
class Solution {
public:
    int numberOfSets(int n, int k) {
        int mod=1e9+7;
        int ans=0;
        vector<vector<int>>dp(n+1,vector<int>(k+1,0));        vector<vector<int>>f(n+1,vector<int>(k+1,0));

        for(int i=1;i<=n;i++){
            f[i][0]=1;
            for(int j=1;j<i&&j<=k;j++){
               dp[i][j]=f[i][j-1]+dp[i-1][j];
               f[i][j]=dp[i-1][j]+f[i-1][j];
               dp[i][j]%=mod;
               f[i][j]%=mod;
            }
        }
        ans=dp[n][k]+f[n][k];
        ans%=mod;
        return ans;
    }
};
```

## 代码分析
- 正确性：正确。小数据可手工验证：n=3、k=1 时逐步算得 dp[3][1]=2、f[3][1]=1，答案 3，与「3 个点选 1 条线段有 C(3,2)=3 种」一致；n=4、k=2 得到 5，与组合公式 C(n+k-1, 2k)=C(5,4)=5 一致。
- 关键实现：两个二维状态互补，`j<i` 这个循环上界同时充当了「i 个点最多 i-1 条线段」的合法性剪枝；`f[i][0]=1` 在每轮重置，保证「前面一条都没选」这一种情况被计入。
- 潜在 Bug：无。取模放在加法之后：两个加数都小于 mod，和不超过 2×1e9+12，仍在 `int`（2^31-1）范围内，不会溢出。
- 可以改进的地方：仅可读性 —— 那一行里两个 `vector` 声明挤在一起，建议分成两行；内层循环体缩进与外面不一致。算法上还可以直接用组合数：答案等于 C(n+k-1, 2k)，用乘法逆元 O(k + log mod) 就能算出来。

## 复杂度
- 时间复杂度：O(n·k)。外层 i 从 1 到 n，内层 j 最多到 min(i-1, k)，总状态数是 n·k 量级，每个状态 O(1) 转移。
- 空间复杂度：O(n·k)。两个 (n+1)×(k+1) 的 int 二维表；由于 `dp[i][*]`、`f[i][*]` 只依赖上一行，滚动数组可以压到 O(k)。

## 易错点
- **循环上界写成 `j<=k` 而不加 `j<i`**：i 个点画不出 i 条线段，多算出来的状态虽然是 0，但会让人误以为答案里含非法方案；更重要的是 `j<i` 让写法与「每条线段至少占两个相邻点」的事实对齐。
- **忘记 `f[i][0]=1`**：这条初始化代表「前面一条线段都没选」，少了它第一条线段就无法通过 `f[i][j-1]` 新开出来，答案会整体偏小。
- **答案只取 `dp[n][k]`**：必须加上 `f[n][k]`，否则会漏掉「最后一条线段在点 n 之前就结束」的所有方案。
- **取模位置**：写成 `(dp[i][j] += ...) %= mod` 时要注意中间结果类型；本题用 int 累加两数不会溢出，但若改成三个数相加或改成 long long 混用，就要留意类型提升。
- **误以为线段不能共端点**：题目允许相邻线段共用端点，所以「i 个点能画 i-1 条线段」是成立的；如果按「端点不可共用」理解，DP 的转移形式会完全不一样。

## 总结
「在直线上选 k 条互不重叠线段」的计数，关键是把方案按**最后一条线段的右端点**分类：右端点是当前点（`dp`）或不是（`f`），两者互补且互相转移，用前缀式的滚动 DP 在 O(nk) 内解决。教科书答案还有一条更短的等价路：答案就是 C(n+k-1, 2k) —— 可以把线段问题转化为「在 n+k-1 个空位里放 2k 个端点的组合」问题，记住这个等价关系能快速校验 DP 结果。

## 复盘
- 容易想错的地方：第一反应通常是枚举每条线段的左右端点，状态维度爆炸；抓住「线段只由右端点刻画」这个不变量，维度立刻降到二维。
- 关键突破点：用一个「不选当前点作为右端点」的辅助状态 `f` 代替前缀和，既省掉了对上一层求和的 O(k) 开销，又让转移保持 O(1)。
- 下次看到什么特征应该想到这个算法：一维直线上「选若干不相交区间 / 线段」的计数问题，且规模在 1e3 量级、需要取模 —— 优先考虑按右端点分类的线性 DP，或者直接推组合数公式。
