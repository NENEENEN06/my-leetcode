# 2243. Calculate Digit Sum of a String

- Difficulty: Easy
- Topics: String, Simulation
- Language: C++
- 题目链接: https://leetcode.com/problems/calculate-digit-sum-of-a-string/

## 题目

把字符串 `s` 每隔 `k` 个字符分一段（最后一段可以不足 `k`），每段里所有数字相加，把和写成字符串接起来作为新的 `s`；重复这个过程直到 `s` 的长度不超过 `k`，返回最后的 `s`。

## 我的思路

- **核心思想**：纯模拟。外层 `while (s.size() > k)` 控制「还能再合并一轮」，内层一遍扫描边累加边按每 `k` 个切段。
- **关键点**：
  - 用 `sum` 累积当前段的数字和，`i % k == k - 1` 表示这一段刚好凑满 `k` 个，于是把 `sum` 转成字符串拼到 `next` 末尾并清零；
  - 循环结束后若 `s.size() % k != 0`，说明尾巴上还有一段没满 `k`，单独把剩下的 `sum` 拼上去；
  - 一轮结束后 `s = next`，继续判断是否还需要再合并。
- **为什么正确**：题目规则是逐段求和再拼接，代码里「满 k 就收一段」和「尾巴单独收一段」正好覆盖了所有分组情况；外层条件保证了终止于 `s.size() <= k`，与题目要求一致。

## 代码

```cpp
class Solution {
public:
    string digitSum(string s, int k) {
        while (s.size() > k) {
            string next;
            int sum = 0;
            for (int i = 0; i < s.size(); i++) {
                sum += s[i] - '0';
                // 每凑满 k 个字符，就把这一段的和转成字符串拼到末尾
                if (i % k == k - 1) {
                    next = next + to_string(sum);
                    sum = 0;
                }
            }
            // 最后不满 k 个的那一段单独收尾
            if (s.size() % k != 0) {
                next = next + to_string(sum);
            }
            s = next;
        }
        return s;
    }
};
```

## 代码分析

- 正确性：力扣站内已 AC（本机未复跑，代码取自该次 Accepted 提交）。
- 关键实现：`i % k == k - 1` 是「凑满一段」的判据，比每次单独算段落边界省一半判断；尾巴那一段用 `s.size() % k != 0` 补，避免漏。
- 潜在 Bug：`next = next + to_string(sum)` 是反复拼接，虽然 `next` 每轮最多几十个字符、代价可以忽略，但严格说用 `+=` 更合适（这里写成 `+` 是为了保持原码形态）。
- 可以改进的地方：`to_string` 也可以用 `char('0' + sum)` 代替——单段最多 `k` 个数字，`k <= 100` 时和可能超过 9，所以还是得用 `to_string`，此路不通。

## 复杂度

- 时间复杂度：`O(n · log_k n)` 量级。每轮至少把长度压缩到约 `1/k`（每段最多两位到三位），轮数是 `log_k n`，每轮扫一遍当前长度。
- 空间复杂度：`O(n)`，每轮都要构造新的字符串。

## 易错点

- **尾巴那一段**：`s.size()` 不是 `k` 的整数倍时，最后剩余的字符必须单独处理，否则会丢数字。
- **`sum` 要及时清零**：收完一段不清零，下一段会带着上一段的残留。
- **终止条件**是 `size() <= k`，不是 `< k`——长度正好等于 `k` 时就不再合并了。

## 总结

- 字符串模拟题的关键是**把「分段」的判据写成下标运算**，比每次 `substr` 干净。
- 「不断缩减直到满足条件」的结构，先想清楚每轮能压缩多少、会终止在哪里，再动手写循环。

## 复盘

- 这题没有算法难点，考的是分段边界别漏；写完后可以手工跑一遍 `s="11111222223", k=3` 来验算。
- 容易忘的是「整个字符串长度不足 k 时直接返回原串」，`while` 条件恰好把这个边界挡住了。
