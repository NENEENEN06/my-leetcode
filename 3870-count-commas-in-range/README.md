# 3870. Count Commas in Range

- Difficulty: Easy
- Topics: Math
- Language: C++
- 题目链接: https://leetcode.cn/problems/count-commas-in-range/description/?envType=daily-question&envId=2026-09-08

## 题目

给定整数 `n`（`1 <= n <= 1e5`），返回将 `[1, n]` 范围内所有整数以标准数字格式书写时用到的逗号总数。标准格式下从右往左每三位插入一个逗号，位数少于四位的数字没有逗号。例如 `n = 1002` 时，`"1,000"`、`"1,001"`、`"1,002"` 各含一个逗号，答案为 3。

## 我的思路

- 核心思想：本题不是模拟每个数字，而是按「是否出现逗号」直接计数。标准格式中，只有位数达到 4 位（即 `>= 1000`）的数字才会插入第一个逗号。
- 使用的数据结构：无，纯数学推导。
- 算法流程：
  1. 数字 `1..999` 都少于四位，不含逗号，贡献 0。
  2. 由于 `n <= 1e5 < 1,000,000`，范围内每个数字最多只有一个逗号。
  3. `1000..n` 每个数字恰好含一个逗号，个数为 `n - 999`；若 `n < 1000`，答案为 0。
- 为什么这样做：先看数据范围确定每个数的逗号个数上限，再用区间长度一步算出总数，避免了逐个数数字的枚举。
- 关键状态 / 变量：只有 `n` 本身，判断它与 `1000` 的关系。
- 为什么能够得到正确答案：`[1000, n]` 的闭区间整数个数为 `n - 1000 + 1 = n - 999`，且每个数字恰好贡献 1 个逗号，累加即为答案。

## 代码

```cpp
class Solution {
public:
    int countCommas(int n) {
        return (n>999)?(n-999):0;
    }
};
```

## 代码分析

- 正确性：正确。
- 关键实现：三目运算符 `(n>999)?(n-999):0` 等价于 `max(0, n - 999)`：`n <= 999` 时返回 0，否则返回闭区间 `[1000, n]` 的长度。
- 潜在 Bug：无。注意该公式成立依赖题目约束 `n <= 1e5`；一旦 `n` 达到 `1,000,000`，该数字会含两个逗号，公式会少算。
- 可以改进的地方：写成 `return max(0, n - 999);` 语义更直白，当前写法结果完全相同。

## 复杂度

- 时间复杂度：O(1)，常数次比较与算术运算。
- 空间复杂度：O(1)，无额外空间。

## 易错点

- 忽略 `1..999` 没有任何逗号，把 `n <= 999` 的情况也算成 `n - 999`（会得到负数或错误结果）。
- 忘记 `n - 999` 的含义是 `[1000, n]` 的整数个数：`n - 1000 + 1`。
- 本题的 O(1) 公式依赖 `n <= 1e5` 这个上界；如果 `n` 更大，需要按 `1,000,000`、`1,000,000,000` 分段考虑多个逗号。

## 总结

这是典型的「脑筋急转弯 / 数学计数」题：先确认数据范围，发现每个数最多只含一个逗号后，答案就退化为 `max(0, n - 999)` 一次算术运算，无需任何模拟。

## 复盘

- 我哪里容易想错：容易下意识去循环每个数字统计逗号，忽略了先观察范围上限能直接化简。
- 关键突破点：`n <= 1e5` 意味着任何数都写不出第二个逗号，计数变成纯区间长度。
