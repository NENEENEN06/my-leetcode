# 3875. Construct Uniform Parity Array I

- Difficulty: Easy
- Topics: Array, Math
- Language: C++
- 题目链接: https://leetcode.cn/problems/construct-uniform-parity-array-i/

## 题目

给定一个互不相同的整数数组 `nums1`，需要构造长度相同的 `nums2`，使 `nums2` 中的元素要么全为奇数，要么全为偶数。每个下标 `i` 可以任选 `nums2[i] = nums1[i]` 或 `nums2[i] = nums1[i] - nums1[j]`（`j != i`）。若能构造则返回 `true`，否则返回 `false`。

## 我的思路

- 核心思想：脑筋急转弯，答案是恒定的 `true`，与输入无关。
- 使用的数据结构：无。
- 算法流程：
  1. 如果 `nums1` 全是偶数，直接令 `nums2[i] = nums1[i]`，得到全偶数数组。
  2. 如果 `nums1` 中至少有一个奇数（记为 `nums1[k]`），则对所有偶数下标令 `nums2[i] = nums1[i] - nums1[k]`（偶数减奇数为奇数），对所有奇数下标令 `nums2[i] = nums1[i]`（保持奇数），从而得到全奇数数组。
- 为什么这样做：奇偶性下，偶数减奇数是奇数；因此只要存在一个奇数，就能把每个偶数元素“翻转”成奇数，同时奇数元素保持不变，最终全奇数。
- 关键状态 / 变量：不需要任何状态，直接返回 `true`。
- 为什么能够得到正确答案：上面的两种情况覆盖了所有可能输入——要么没有奇数（全偶数可构造），要么至少有一个奇数（全奇数可构造），因此永远可行。

## 易错点

- 容易被“构造”两个字带偏，去写模拟或分类讨论；实际上只要想清楚奇偶性，就能发现答案恒为 `true`。
- 注意题目允许每个下标独立选择 `j`，且 `j != i`，这是“全奇数构造”成立的前提。
- 若以后遇到类似“Uniform Parity Array II”，约束可能变严，不能直接照搬 `return true`。

## 总结

这道题最值得记住的是奇偶性观察：偶数减奇数为奇数。只要数组里有一个奇数，就能用它把所有偶数都变成奇数，从而构造出全奇数数组；没有奇数时本身就是全偶数，所以答案恒为 `true`。
