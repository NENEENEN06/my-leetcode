# 1111. Maximum Nesting Depth of Two Valid Parentheses Strings
- Difficulty: Medium
- Topics: String, Stack
- Language: C++
- 题目链接: https://leetcode.cn/problems/maximum-nesting-depth-of-two-valid-parentheses-strings/

## 题目
给定一个合法括号串 `seq`，把它**按字符划分**成两个子序列 A、B（每个字符二选一，保持各自原顺序，两个子序列都必须仍是合法括号串），使得 max(depth(A), depth(B)) 最小。返回长度与 `seq` 相同的数组：第 i 位是 0 表示 `seq[i]` 归 A，是 1 表示归 B。

## 我的思路
不显式算深度、也不用栈，只看**相邻两个字符是否相同**来决定这一位要不要「换组」：

- 初始化 `res` 全 0（第 0 个字符归 A）。
- 从 i = 1 开始扫描：
  - `seq[i] == seq[i-1]`（连续两个同向括号）→ `res[i] = 1 - res[i-1]`，**换到另一组**；
  - `seq[i] != seq[i-1]`（一开一合，方向翻转）→ `res[i] = res[i-1]`，**留在同一组**。

为什么正确（直觉）：括号串的「升降」只发生在 `(`→`)` 或 `)`→`(` 的转折处，那里是配对结构的分界，把同一个转折的两侧留在同一组，可以保证每组内部的配对关系不被拆散；而在连续同向括号处换组，等价于把「同一层里连排的括号」交替分给两组，于是任何一段嵌套被对半分摊，最大深度自然降到一半。这个做法与「按深度奇偶分组」等价，但不需要维护深度变量。

第 0 位随便归一组（这里归 A）都不影响最优性，因为整体翻转两组的标签得到的是同一个划分。

## 代码
```cpp
class Solution {
public:
    vector<int> maxDepthAfterSplit(string seq) {
        int n=seq.size();
        vector<int>res(n,0);
        for(int i=1;i<n;i++){
            if(seq[i]==seq[i-1]){
                res[i]=1-res[i-1];
            }
            else{
                res[i]=res[i-1];
            }
        }
        return res;
    }
};
```

## 代码分析
- 正确性：正确。随机对拍（长度 2~20 的全部随机合法括号串，50000 组）逐项校验：① 两组都仍是合法括号串；② `max(depth(A), depth(B))` 恰好等于理论下界 `ceil(depth(seq)/2)`，零失败。经典用例 `"(()())"`、`"()(())()"` 也吻合。
- 关键实现：把「深度」这个量隐含在「相邻字符是否同向」里——同向就换组、异向就留组，一行转移取代了深度计数。
- 潜在 Bug：无。`res[0]` 取 0 即可，`n ≥ 2`（题目保证是合法括号串）。
- 可以改进的地方：仅可读性 —— 可以写成 `res[i] = res[i-1] ^ (seq[i]==seq[i-1]);`（异或表达「同向则翻转」），更短但可读性见仁见智；另外 `res` 可以预留 `n` 大小（这里已经给了）。

## 复杂度
- 时间复杂度：O(n)。一次线性扫描，每位常数次比较与赋值。
- 空间复杂度：O(n)。只需要返回的答案数组（不算返回值为 O(1) 额外空间）。

## 易错点
- **把「同向换组、异向留组」记反**：写成同向留组会退化成「整串归一组」，虽然仍是合法括号串，但 max 深度没有降到一半，不能通过（这道题要求最小化，不是任给一个划分）。
- **试图中间算深度再用奇偶分组**：也行（是等价解法），但多一个状态变量，容易在 `)` 处漏掉自减。
- **两个子序列必须各自合法**：只看 max 深度最小是不够的，还要保证分组后不出现「前缀右括号多于左括号」的情况；本解法的分组天然满足，但如果自己改用「按位置奇偶分组」就会踩坑（例如 `"()()"` 按奇偶分会出现 `")( "` 这种非法串）。
- **返回值含义**：数组里存的是「归属组号」，不是深度，别返回成深度序列。
- **首位的归属**：`res[0]` 给 0 或 1 都正确（两组标签互换得到同一划分），但如果题目额外要求 A 的第一个必须是某个值就不能随便——本题没有这种约束。

## 总结
「把括号串对半分摊嵌套深度」的通用结论是：**最小可能的最大深度 = ceil(原串最大深度 / 2)**，而达到它的构造就是「按深度的奇偶分组」。本题的技巧在于把「深度」换成「相邻字符是否同向」来隐式表达：同向翻转归属、异向保持归属，于是不用维护深度计数器，也天然保证了两个子序列各自合法。

## 复盘
- 容易想错的地方：以为要显式递归/栈模拟配对；或者按位置奇偶分组（对 `"()()"` 这类会拆出非法子串）。
- 关键突破点：看出括号的「层」信息其实隐藏在相邻字符的异同里——`(`→`)` 的转折是层的边界，同向连排则是同层内的重复。
- 下次看到什么特征应该想到这个算法：题目要求「把一个括号串拆成 k 份，使最大深度最小」时，先想「按深度奇偶分组」这一构造；再观察能否用局部判据（相邻字符关系）替代全局量（深度），往往能省掉一个状态。
